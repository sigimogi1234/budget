# 우리 가계부

신랑·신부가 각자 링크로 접속해서 같이 쓰는 커플 가계부 웹앱입니다.

## 기능

- **수입**: 신랑 / 신부 구분, 분류(월급·기타)
- **지출**: 신랑 개인 / 신부 개인 / 공용, 대분류·소분류(설정에서 직접 추가·삭제), 사용 카드, 비상금(변동) 지출 표시
- **저축**: 신랑 / 신부 구분, 각자 누적 저축액과 둘이 합친 총 저축액
- 모든 내역: 날짜, 금액, 내용, 비고
- **예산**: 월 지출 예산과 비상금 예산을 따로 설정, 남은 금액 표시. 달마다 다른 예산을 설정할 수도 있음
- **카드 혜택**: 카드마다 혜택률(%), 월 혜택 한도, 전월 실적 조건을 등록하면 매달 카드별 사용액으로 예상 할인·캐시백을 계산. 설정에서 켜면 혜택을 뺀 실질 지출로 예산을 계산
- **월별 요약 / 연간 정리**: 월별 수입·지출·저축 흐름, 분류별 지출, 카드별 연간 혜택
- JSON 백업 내보내기 / 가져오기

## 둘이 같이 쓰기 (Firebase 연결, 무료, 약 5분)

`firebase-config.js`가 비어 있으면 **로컬 모드**로 동작합니다. 로컬 모드에서는 데이터가 그 브라우저에만 저장됩니다.
둘이 같은 데이터를 보려면 Firebase를 연결하세요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정
3. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, **프로덕션 모드**)
4. Firestore **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**
5. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(</>)** 앱 등록 → 표시되는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기
6. Authentication → 설정 → **승인된 도메인**에 `<GitHub 아이디>.github.io` 추가
7. 커밋 & 푸시하면 끝.

연결 후 사이트에 처음 들어가서 **새 가계부 만들기**를 누르면 `#code=...`가 붙은 링크가 생깁니다.
이 링크를 상대방에게 보내면 같은 가계부를 함께 쓸 수 있습니다. 설정 › 공유에서도 링크를 복사할 수 있습니다.
링크를 가진 사람은 누구나 접근할 수 있으니 둘만 공유하세요.
